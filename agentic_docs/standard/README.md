# The standard: how to read this folder

For the agent. This folder is a **copy** of the owner's standard, taken from the `standard/` folder of the `standardization` repo (`~/Workspace/github/iisharankov/standardization` on the laptop). Version 0.3, 2026-11-08. The owner copies it into each project at `agentic_docs/standard/` and refreshes it by hand when the original changes.

**Never edit the files in this folder.** They are the owner's, and the next copy would overwrite your change. When something here is wrong or missing, say so in the hand-back under "For the standard", and the owner carries it to the original.

## Read in this order

1. [profile.md](profile.md): who the owner is, how he works, and what the laptop and the server can and can't do. Facts no project asks again.
2. [agents.md](agents.md): the rules, the round, questions and answers, the owner's steps, the docs layout, the hand-back, and the templates. Read it once in full in your first session on a project; after that, section 4 (the round) and section 11 (the hand-back) are the parts you use every time.
3. [adopt.md](adopt.md): only when the project already has docs of its own and the owner asks you to adopt the standard.

Then the project's own files, in the order its `CLAUDE.md` gives: `agentic_docs/agents/notes.md`, `agentic_docs/questions.md`, the newest three files in `agentic_docs/rounds/`.

## Which version the project follows

The project's `CLAUDE.md` names the version it follows. When this folder's version is newer than that, the owner has refreshed the copy: read the "Versions" section at the end of agents.md and apply the differences to the project's docs in a round of its own, docs only, before other work.

## What is in the original and not here

The original repo also holds the owner's own page (`README.md` at its root: his part, the words agents understand, prompts to paste) and the six project reports the standard was merged from. Neither is needed in a project.
