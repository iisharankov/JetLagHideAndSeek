# Roadmap

Ideas and what's next, in a suggested order. Updated 2026-11-09 (round 29). What was built is in `rounds/` and `history/rounds-before-the-standard.md`; bugs are in `known-issues.md`.

## Next

1. **The November game's fixes** ([plans/nov-game-fixes/](plans/nov-game-fixes/README.md)): identity and team roles (A), hider sync (B), the thermometer as the rulebook plays it (E) before the next game night; then the phone-first layout (C, D), metric and photos (F).
2. **A shakedown game** after A, B and E, with two phones on one table first: one reload each, one phone swap.
3. **The public site's gates** (Q47) and the backup schedule (Q48, S4).

## Later

4. **Several areas on one server** (old Q43: Switzerland, Zürich, Munich, cities further away): one pack, tile file and elevation set per area, picked by the play area. Sizes and what it takes are in `history/questions-before-the-standard.md` (Q43) and [../docs/guides/areas.md](../docs/guides/areas.md).
5. **Cleanups** from the audit (known-issues 1, 6, 7, 9, 12, 13, 14): the Overpass client out, duplicates, dead exports, lazy Places counts, a name index for the search.
6. **Tests** (known-issues 17–19): the zone layer, the answer suggestions, a pack smoke test, the shared-game flows on the phone project.
7. **The live view without the archive** (known-issues 8); the bundle (15); a worker only if a real game stutters (11); the offline map (10).
8. **Rest periods checked after one night's use** (known-issues 4).

## Dropped

- Per-area offline data packs on the phone (only if signal turns out to be a real problem in play).
- An Android APK: install the web app instead.
